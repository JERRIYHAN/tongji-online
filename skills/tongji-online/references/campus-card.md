# 一卡通：服务中心

入口：`https://yikatong.tongji.edu.cn/ppage/service`。页面标题“服务中心”，页头“应用中心”。本文件覆盖该页“校园卡类”的 7 项服务，以及各自的“查看说明”和业务入口。目录核对日期：2026-10-23。

查校园卡余额、消费流水，或定位宿舍缴费、校园卡挂失／解挂及查询密码修改时，读取本文件。通过浏览器复用官网认证，登录后回到服务中心继续；现有 CLI 的 `auth login --service` 不包含一卡通。

## 功能目录

每项服务包含三个独立点击区域：**服务名称与简介**进入业务，**查看说明**打开官方介绍，**收藏**修改常用设置。查询或探索时按前两种入口定位。

| 服务 | 功能与官方说明 | 应用编号 `appid` | 业务流程 `flowID` |
| --- | --- | ---: | ---: |
| 水电缴费 | 为宿舍缴费；官方说明列出支付宝、微信和上海地区发行的农行卡 | 135 | 31 |
| 图书馆 | 查询图书借阅情况 | 101 | 140 |
| 余额查询 | 查询校园卡账户余额 | 44 | 14 |
| 消费查询 | 查询交易流水 | 47 | 15 |
| 修改密码 | 修改校园卡查询密码；官方说明指一卡通综合管理平台或掌上校园的登录密码 | 43 | 3 |
| 卡片解挂 | 遗失的校园卡找回后，恢复卡片功能 | 46 | 12 |
| 卡片挂失 | 校园卡丢失后办理挂失 | 45 | 2 |

“修改密码”对应一卡通平台密码，不是学校统一身份认证密码。图书馆服务对应借阅查询；座位与研习室使用各自的 [空间预约流程](library-seats.md)。

## 常用任务

### 查询余额

1. 在服务中心点击“余额查询”的名称／简介区域。
2. 业务页标题为“余额查询”，读取“校园卡账户”中的“余额”。
3. 按页面上的账户名称对应余额，向用户返回本次所需的信息。

### 查询消费流水

1. 点击“消费查询”，进入标题为“流水”的页面。
2. 使用两个日期框选择查询范围，控件标识为 `#txts1`、`#txts2`，类型为日期选择器。
3. 读取表格并按需翻页。每页条数可选 15、30、45、60、75、100；汇总某段时间的消费时，覆盖筛选后的全部分页。

表格字段：

| 页面列名 | 字段标识 | 使用方式 |
| --- | --- | --- |
| 入账时间 | `EFFECTDATE` | 区分记账日期与实际交易日期 |
| 交易时间 | `OCCTIME` | 整理用户指定时段的交易 |
| 交易地点 | `MERCNAME` | 展示或归类消费地点 |
| POS | `POSCODE` | 终端编号，排查某条交易时按需读取 |
| 交易金额 | `TRANAMT` | 结合交易类型区分消费、充值等流水 |
| 交易类型 | `TRANNAME` | 解释金额对应的业务，按类型统计 |
| 卡余额 | `CARDBAL` | 该笔流水对应的卡余额，与当前账户余额分别说明 |

汇总时先核对日期范围、金额和交易类型，再计算笔数及金额；不把充值等非消费流水混入消费总额。

### 定位宿舍缴费

“水电缴费”入口当前打开的业务页标题为“缴电费”。表单包含：

- 宿舍位置：区域 `#areas` → 楼栋 `#building` → 楼层 `#floor` → 房间 `#room`，另有房间编码 `#roomid`。
- 支付方式 `#paytype`：一卡通账号、绑定的银行卡、网关支付。
- 金额 `#money`，以及“缴费”“取消”按钮。

先定位用户指定的宿舍，再填写金额、选择当前可用的支付渠道。官方说明中的渠道介绍与业务表单中的支付方式分开理解；具体渠道在相应选项下继续选择。缴费按用户明确授权办理，提交前核对房间、金额和支付方式。

### 图书借阅、密码及卡片状态

- **图书馆**：该服务介绍为“查询图书借阅情况”。查询本人借阅和应还日期时，可优先使用已有 [图书馆查询](library.md)。
- **修改密码**：从此入口定位一卡通平台密码修改页面，密码输入与提交由用户完成。
- **卡片挂失／卡片解挂**：分别对应丢卡停用与找回恢复。按用户要求进入相应业务，完成后核对卡片状态或办理结果。

## 导航与说明页

服务项通过 `onclick="goPage(...)"` 导航，不是普通的 `href` 链接。前端函数位于当前页面加载的 `/Scripts/common/page.js`，它填入 `flowID`、`type`、`apptype`、菜单名等字段，再通过表单 **POST `/Page/Page`** 打开选中的业务。

余额、流水、缴费等不同业务都可显示为 `/Page/Page`。下次从服务中心按名称点击；只保存或直接打开这个地址无法指定具体业务。确认位置时同时看页面标题和目标控件。

目录异步加载：先等“校园卡类”和目标服务出现，再读取列表。外层可访问性树有时只显示页头与底部导航，这时读取页面 DOM（文档对象模型，即实际网页元素）即可取得服务项。按服务名称或所在条目定位“查看说明”，避免依赖全页序号。

各项官方说明使用同一地址结构：

```text
/Category/pPageServiceDetails?appid=<应用编号>&burl=/Ppage/Service
```

应用编号从上表或当前服务项的 `appReadMe(...)` 参数取得；业务流程编号从同一项的 `goPage(...)` 参数取得。两类编号用途不同。页面更新时重新提取当前条目的名称、简介、说明链接和导航参数，更新本文件即可。

公共文档保留目录、字段和流程；个人余额、消费地点与时间、宿舍房间、密码和会话凭据留在当次任务中。目录探索使用名称和“查看说明”，不触发收藏、缴费、挂失、解挂或密码修改。
